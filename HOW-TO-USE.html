3StreamElements: the 4 copy-pastes

  1. Go to streamelements.com and log in with your Twitch account.
  2. Open Streaming tools > Overlays > New overlay (choose 1920 x 1080).
  3. Click the + button (Add widget) > Static / Custom > Custom widget.
  4. Select the new widget, then click "Open editor" in the left panel.
  5. You now see tabs: HTML, CSS, JS, FIELDS, DATA. For each of the 4 files below: click the tab, select everything already inside (Ctrl + A), then paste (Ctrl + V). Leave the DATA tab as it is.
  6. Click Done, then Save (top right). The settings of the chat appear in the left panel.
  7. Resize the widget box where you want the chat on your overlay.
  8. Copy your overlay URL (link button at the top), then in OBS: + › Browser › paste it › 1920 x 1080.

?Something doesn't work?

The chat stays empty

The chat only shows new messages: type something in your Twitch chat. In the StreamElements editor, use the "Emulate" button to send test events.

I pasted and nothing appears in StreamElements

Make sure each file went into the right tab and that you replaced everything that was there before (Ctrl + A first). Then click Done and Save.

The text is too small or too big

Change the "Text size" setting.

Donations show in the wrong currency

Change "Currency for donations": Dollar by default, Euro, Pound, or Automatic (your StreamElements currency).

Does it work on Kick or YouTube?

No, this widget reads Twitch chat only.
